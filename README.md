# Savage Arms 🔫

A full-stack web application built using the **MERN stack** (MongoDB, Express, React, Node.js), focused on managing and displaying firearms for sale. It includes dynamic filters, user roles, and company-based controls.

---

## 🌟 Features

- 🔍 Search and filter firearms by caliber, model, type, and price
- 🧑‍💼 Role-based access (User, Admin, Company)
- 🏢 Companies can add/edit firearms
- 🧾 Full CRUD for firearms
- 🖼️ Cloudinary integration for image upload and storage
- 🔐 JWT-based authentication and authorization

---

## 🧰 Tech Stack

- **Frontend**: React.js, React Router, Axios, Tailwind CSS
- **Backend**: Node.js, Express.js, MongoDB, Mongoose
- **Authentication**: JWT
- **File Upload**: Multer + Cloudinary
- **Deployment**: Vercel (Frontend), Render/Heroku (Backend)
